# Repository instructions

Replace this starter with repository-specific instructions before enabling AI
implementation.

## Architecture

Document the important modules, dependency direction, public interfaces, and
where new behaviour belongs.

## Coding conventions

Document language, formatting, naming, error-handling, dependency, and testing
rules.

## Commands

Keep this list aligned with `.github/agent.yml`:

- Install: `npm ci`
- Format check: `npm run format:check`
- Lint: `npm run lint`
- Test: `npm test`
- Build: `npm run build`

## Prohibited changes

Document files, behaviours, dependencies, and architectural boundaries the agent
must not change.

## Deployment

Document deployment and release steps. The AI agent must not deploy or merge.
